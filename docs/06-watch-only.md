# 06 — WATCH_ONLY / 人工观察模式

## 定位

WATCH_ONLY 是系统的核心观察视图，用于人工观察通过全部安全校验的比赛。正式自动化信号（Official Alert）保持 **DISABLED**。

## 展示内容

- 当前 Asian Total 盘口与大/小球赔率
- Remaining Goals λ（market 与 model）
- 五态结算概率（P_WIN / P_HALF_WIN / P_PUSH / P_HALF_LOSS / P_LOSS）
- P_POSITIVE（WIN + HALF_WIN）
- 短期进球概率 P3 / P5 / P7 / P10
- P_HT / P_FT
- Top 5 / Top 10 动态排名
- 比赛结束后自动结算

## 标记

页面持续显示：

- `WATCH_ONLY`
- `NO PROVEN EDGE`

强调仅为观察，不构成投注建议。
