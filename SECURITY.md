# Security / 安全

## 本公开仓库不包含 / This repository does NOT contain

- credentials / 凭据
- private feeds / 私有数据源
- production endpoints / 生产接口
- tokens / API keys / cookies / authorization headers
- provider-specific integrations / 数据供应商特定集成
- raw event payloads / 原始事件数据
- private runtime configuration / 私有运行配置
- absolute local paths / 本机绝对路径
- data scraping or anti-bot implementation / 数据抓取与反爬实现

## 数据来源命名 / Source naming

All data sources in public documentation are referenced by neutral names only:

- `Live Match Stream` / `LIVE_DATA_PROVIDER`
- `Primary Asian Total Market` / `PRIMARY_MARKET_SOURCE`
- `Secondary Confirmation Feed` / `CONFIRMATION_SOURCE`

No real provider, bookmaker, website, or endpoint names appear anywhere in this repository.

## Reporting

If you discover any sensitive information in this public repository, please contact the author immediately.
