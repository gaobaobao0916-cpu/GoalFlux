# Demo Data / 演示数据

## Synthetic Demo Data

The JSON files in this directory (`mock_watch_records.json`, `mock_settlement_records.json`) are **synthetic examples for demonstration only**.

- They do **not** come from any real match, provider, or data feed.
- Team names are invented (Demo FC, Sample United, etc.).
- All probability and settlement values are illustrative.

## Purpose

These files demonstrate the shape of WATCH_ONLY records and settlement records used by GoalFlux, without exposing any real production data.
