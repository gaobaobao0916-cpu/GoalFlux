## 中文

GoalFlux 是由「随心笔记」持续设计与迭代的独立软件工程项目，重点研究实时足球概率建模、亚洲大小球结算、运行时数据质量与人工观察分析。

系统参考现代智能数据系统中的实时流处理、特征工程和概率分析方法，采用类似先进实时分析平台的系统设计理念，构建面向复杂动态环境的数据驱动研究框架。

## English

GoalFlux is an independent software engineering and quantitative analysis project designed and iterated by **随心笔记**, focused on real-time football probability modelling, Asian Total settlement, runtime data quality, and observation-oriented analytics.

The system references real-time stream processing, feature engineering, and probabilistic modelling methods from modern intelligent data systems, adopting design principles similar to advanced real-time analytics platforms, providing a data-driven research framework for complex dynamic environments.

### Roles

- Project Lead
- System Design
- Architecture
- Research Direction
- Product Design
- Data Engineering
- Machine Learning Applications

GoalFlux is not affiliated with any data provider, bookmaker, or financial institution. All probabilities and settlement outputs are for research purposes only and do not constitute investment or betting advice.
